## Surprises

- Dead code (.cc not in CMake or header never included): cDemeTopologyNetwork 341, cMultiProcessWorld 309, cWeightedIndex 77, cProbDemeProbSchedule 76, cDemeProbSchedule 74, sCPUStats 46, migration_message 31, NetworkDistanceVisitor 15, Avida::Environment::ContextFactory 7, Avida::Environment::Context 4.
- `source/script` (7306 lines) is in no CMake source list and no `avida-s` target exists, yet 28 `_asl_*` tests need it; the Rust `script` crate covers it.
- Built but required by no test: cHardwareBCR (4466 lines), cHardwareGP8 (3727); 336 unused actions. The optional ncurses viewer targets (`avida-viewer`, `avida-text`) and the `viewer` library are not part of the CLI.
- 7 tests name actions that are not registered at this commit (PrintStatsData, SaveHistoricPopulation); `cEventList::AddEvent` returns false for them, so `_analyze_detail_all`, `default_transsmt_100u` (both with expected output) cannot load as written. `_task_optimize_lim_res`, `heads_default_500u`, `hoarding_collect_internal_300u`, `large_pop`, `migration_div_mut_rate_inject_test_500u` have no expected output.
- `default_transsmt_100u` and `_analyze_detail_all` also have no loadable instruction set (non-legacy cfg without INSTSET block; legacy file but INST_SET_LOAD_LEGACY unset).
- Duplicated logic: 150 instruction handler names exist in more than one hardware class (3910 duplicate lines beyond the largest copy, e.g. Inst_Repro in 4 classes); two `cTextWindow` classes (avida-viewer, viewer-text); `cWeightedIndex` (uncompiled) next to `cOrderedWeightedIndex`; Systematics Unit/Group/Genotype/Clade split across public and private headers.
- test_matrix.json action lists include file names and argument words (48 distinct tokens that are not action names), and its `hw` field is empty for tests that use the default hardware; instruction sets were therefore re-derived from the configs. Two matrix tests (`analyze_printphenotypes_grouping`, `manager_provider_id_dispatch`) are not in the 47f13dadb tree and were read from the working tree.
- Largest single blocker: cAnalyze (11285 lines) is needed by 16 analyze-mode tests only; cHardwareExperimental (7552 lines) by 4.
