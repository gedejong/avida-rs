# Getting started

This section takes you from nothing to a finished first run and a reading of its results. Each page ends with something you can check.

1. [Install and build](install.md): the Rust toolchain, the three programs, and where the build puts them.
2. [Your first run](first-run.md): copy the stock configuration, run 1,000 updates, and read the progress lines.
3. [Output files](output-files.md): what every file in the `data` folder contains and how to plot it.

If you would rather watch than read, build `avida-tui` and start it in your experiment folder after step 2. The [terminal interface](../front-ends/tui.md) page lists its keys.

## What you need

- A computer with a command-line shell.
- About 2 GB of free disk space for the build.
- A Python 3 interpreter is useful for plotting and for the helper scripts in the worked experiments, but the simulation itself does not need it.
